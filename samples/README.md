# samples/

Sample artifacts for the AI governance audit infrastructure.

| File | Description |
|------|-------------|
| [`audit-log-sample.jsonl`](audit-log-sample.jsonl) | 5 representative audit log entries across all supported formats |
| [`audit-log-annotated.md`](audit-log-annotated.md) | Field-by-field explanation of every log schema variant |

## Usage

The `.jsonl` file contains valid JSON lines parseable by `audit.py`:

```bash
# Parse check
python3 -c "import json; [json.loads(l) for l in open('samples/audit-log-sample.jsonl') if l.strip()]"

# Run audit report against production log
python3 -m tools.trustless_audit.src.audit 2026-01-01 2026-12-31
```

The annotated Markdown is reference documentation — not parsed programmatically.
